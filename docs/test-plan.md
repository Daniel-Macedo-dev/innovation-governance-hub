# Plano de testes

Testes cobrem gate bloqueado/permitido e histórico, cálculos monetários/zero, CRUDs de iniciativa, IA e despesas, documentos seguros, reuniões/decisões/pendências, adoção e aprovação de IA, provedor local/factory, n8n desabilitado, automações, importação Excel transacional, workbook e autenticação da API. Validação operacional cobre seed duplo, JSON n8n, templates, roundtrip completo, todas as páginas Streamlit, API e Compose. Integrações externas usam mocks quando não há credenciais.
